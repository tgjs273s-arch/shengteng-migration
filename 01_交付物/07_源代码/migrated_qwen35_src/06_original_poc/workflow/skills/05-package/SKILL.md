# 技能 05：Skill 封装与交付物清单（T8）

## 目标

把已跑通的迁移流程封装成复赛要求的"能自动完成迁移的 Skill 文件夹（.zip）"。

## Skill 目录形态（最终交付结构）

```
skill_qwen35/
├── SKILL.md              ← 总入口：触发条件、输入契约、执行流程
├── analyze/              ← 迁移前分析（初赛 poc1 的 AST 识别升级而来）
│   └── parse.py          ← 自动识别迁移点
├── migrate/              ← 迁移执行
│   ├── weight_convert.py ← 权重转换
│   └── op_adapt/         ← 算子适配（含 GDN 实现）
├── verify/               ← 迁移后验证
│   └── compare.py        ← 数值对比 + 冒烟
├── report/               ← 自动生成迁移报告
│   └── gen_report.py
└── README.md             ← 使用说明、依赖、一键运行命令
```

## 封装验收标准

1. **全新环境一键跑通**：在干净环境执行 `python -m skill_qwen35` 能完成"分析→迁移→验证→报告"全链路；
2. 每步有日志与退出码，失败即停并给出原因；
3. 不依赖任何硬编码的绝对路径（路径走配置/参数）。
