# 技能 02：算子迁移三级决策（T3/T4）

## 适用对象

迁移点清单中的每个算子（来自初赛 poc1 的识别结果 + 官方样例对照）。

## 三级决策流（每个算子必须走完）

```
第1级 探测复用：官方样例 / MindSpeed-MM / CANN 算子库中有无现成实现？
  ├─ 有 → 写适配层直接复用【优先，成本小时级】
  └─ 无 ↓
第2级 组合实现：能否用标准算子组合出数学等价计算？
  ├─ 能 → 纯 PyTorch 实现（先求对不求快）
  └─ 性能不达标 ↓
第3级 自研：昇腾 Triton 重写（进阶）；仍不达标才考虑 Ascend C（冲刺，需人工决策）
```

## 每个算子的标准作业流程

1. **探测**（只读，不写实现）：
   - 在官方样例代码中搜索同名/同义算子；
   - 列出该算子的：数学含义、输入输出形状、依赖的底层原语；
   - 产出 `docs/op_probe_<算子名>.md`，每条结论标注来源：【样例代码:文件行号】/【官方文档:链接】/【推测-待核实】。

2. **决策**：根据探测结果选择级别，在探测文档中写明选择理由。

3. **实现**：
   - 先给实现计划（输入契约/输出契约/等价性论证），用户确认后写码；
   - 代码放入项目约定的模块位置，保持输入输出契约不变。

4. **验证**（调用技能 03）：
   - `verify/compare.py` 逐层对比，余弦相似度 > 0.999；
   - 失败 → 定位误差最大层 → 修复 → 重跑全量对比。

## 本项目已知算子清单（初赛识别）

| 算子 | 类别 | 预判级别 | 备注 |
|---|---|---|---|
| Conv3d / 3D视觉嵌入 | 标准 | 1-2 | 探测 CANN 支持度 |
| RMSNorm | 标准 | 1-2 | 常见，大概率可复用 |
| 全注意力（含视觉塔） | 标准 | 1-2 | 参照官方样例 |
| GatedDeltaNet（chunk_gated_delta_rule） | 自定义 | 2-3 | **核心难点**，无现成实现 |
| causal_conv1d | 自定义 | 2 | 社区有参考实现可借鉴 |
| 门控/状态更新机制 | 自定义 | 2-3 | 随 GDN 一并处理 |

## 纪律

- 探测阶段禁止写实现代码；
- 第 3 级（Triton）开始前必须已完成第 2 级并留有基线数据（性能对比需要基线）;
- 每个算子完成后更新 `docs/op_status.md`（算子状态总表：级别/状态/精度/性能）。
