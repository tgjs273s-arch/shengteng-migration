# T7 · 性能优化循环（复制到 dsh 会话）

先阅读 workflow/rules/ascend-facts.md 和 workflow/skills/04-perf/SKILL.md。

任务：执行 T7——性能优化循环（40 分主战场）。

按 04 技能七步循环执行：
1. 先采基线：msprofiler 采集当前版本，产出 Top 算子耗时榜（命令参数以官方文档为准，不确定先问我）；
2. 从 Top 算子中选择本轮唯一优化目标，提出一个假设并说明依据；
3. 只改这一个变量；改完先过 03 技能守门（精度不劣化），不通过即回滚；
4. 重跑基准：首token延迟 / 端到端延迟 / 吞吐，记录改前改后数据；
5. 结果写一行进 docs/perf_table.md（轮次/假设/改动/前后数据/结论）；
6. 改善则保留进下一轮，否则回滚换假设。连续 3 轮无改善则换方向。

优先方向：GDN 自研算子 > 注意力/视觉塔融合 > 输入流水线 > 精度模式。
一次一轮，本轮从 `<基线采集>` 开始，先给本轮计划。
