## 一、创意缘起：从"改好的代码"到"会改代码的流程"

大模型结构迭代速度已远快于专用芯片的算子适配速度。Qwen3.5 引入的 GatedDeltaNet 线性注意力、
视觉 3D-Conv patch embedding、FusedRMSNormGated 等新结构，在昇腾 NPU 上没有现成的等价实现，
传统迁移依赖专家逐行阅读源码、手工替换算子、逐层调试验证——**不可复用、不可复现、不可规模化**。

市面上的"迁移作品"交付的是"改好的模型"；本项目交付的是**"会改模型的流程"**——一个可复用、
可复现、证据可溯源的自动迁移 Skill：输入 HF 风格建模源码，自动完成迁移点识别、迁移方案生成、
算子级验证与性能基准，直接回应赛题"输入模型 → 自动完成昇腾适配"的字面要求。

## 二、技术路线：五阶段自动流水线（每一环都有已验证证据）

| 阶段 | 能力 | 已验证证据（初赛 POC 真实产出） |
|---|---|---|
| P0 env-probe | 环境探测，决定有卡轨A/无卡轨B | 双轨探测脚本实跑通过 |
| P1 analyze | AST 静态识别 4 类迁移点 | 对 transformers v5.2.0 真实建模源码**命中 49 处**（GatedDeltaNet 26、激活/归一化 13、3D-Conv 7、全注意力 3），行号与符号真实可查 |
| P2 migrate | 依据官方 fsdp2 迁移指南生成 MindSpeed-MM 落点方案 | 落点映射规则表（每类迁移点→目标文件/适配方式/验收标准） |
| P3 verify | 算子矩阵 forward/shape 贯通 + CPU↔NPU 数值一致性 | 4 类算子 3 类真贯通；GDN chunk 算子诚实标 contract-only |
| P4 bench+scene | 性能逐轮优化数据落盘 + 工业场景冒烟 | 基线轮 JSON 已产出；场景推理契约与依赖门槛实测 |

**双轨设计**是本项目最鲜明的工程决策：有卡走真 NPU 实测；无卡走 CPU 证明 shape 等价并如实标注。
这让评委在任何机器上都能复现"识别→验证"证据链，而不依赖一台特定服务器。

## 三、创新点

1. **AST 程序化界定迁移范围**：迁移对象不是人工拍脑袋圈定的，而是解析器对真实源码扫描出的
   4 类 49 处命中，带行号、带符号——迁移范围可审计、可增量更新。
2. **双轨可复现验证**：识别（静态）与探测（运行时）交叉印证，一静一动双重确认；
   无自定义 kernel 的算子标 contract-only 只声明 shape 契约——不伪造任何数字。
3. **证据即交付**：Skill 每轮运行自动落盘全量日志、逐轮性能 JSON、验证矩阵——
   报告里的每个数字都能回溯到日志编号，"从第一天的日志"就是交付物本身。
4. **双场景闭环**：COCO 数据集出精度/性能硬数据（40 分主战场）；
   工业 SOP 判定场景出应用价值（创新+商业 40 分）——硬软件两条腿。

## 四、应用场景与商业价值：工业"操作规范/工艺手法"判定

**场景**：看工业监控画面，判断操作手法是否符合标准作业程序（SOP）——例如法兰螺栓紧固
是否走对角交叉顺序、是否单边连续拧紧，输出结构化 JSON：{compliant, step, issue, evidence, bbox, confidence}。

**为什么必须是大模型**：该判定需要"语义 + 动作时序 + 常识推理"三重能力，
Qwen3.5 原生多模态的视觉 3D-Conv 恰好建模动作过程而非静态帧——这是传统 CV 小模型不可替代之处。

**商业价值**：工业质检正从"事后抽检"走向"过程合规"。SOP 合规判定可平移到电力作业票、
化工巡检、医疗操作规范等高价值场景；落车昇腾边缘盒子/一体机即可形成私有化部署产品形态。
