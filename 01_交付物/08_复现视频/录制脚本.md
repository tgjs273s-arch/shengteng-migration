# 复现视频录制脚本（3–5 分钟，终端录屏为主）

> 交付物 #8（**官方标注为可选**，但它是"全过程可信"的最强证据，强烈建议录）。
> 目标：评委看完能在 **5 分钟内相信**"这套流程真的能自动跑通"，而不是只看我们的报告。
> 录制原则：**终端为主、少口播**；关键行停下 2 秒；**绝不出现 token / 密码 / 跳板地址**。

---

## 一、录前准备（10 分钟，别录进废操作）

1. 打开一个**干净终端**，字号调到 **16–18pt**（录屏后看得清）。
2. 把提示符里的主机名/内网 IP 处理掉（或录完后打码）：`export PS1='$ '`。
3. 预先准备好**一条**命令（见第三节），**中途不要现场敲长命令**。
4. 确认屏幕**没有**：SSH 连接命令（含 token）、密码、跳板 IP、`199.93.x.x`。
5. 关掉聊天窗口/邮件提醒。

## 三、要用的命令（按顺序，可直接复制）

```bash
# 1) 无卡自检（本地或真机都可）
cd qwen35-ascend-migrator
python3 selfcheck.py                       # 期望 SELFCHECK_OK

# 2) 判定链 0-GPU 复现（用包内示例）
python3 scripts/70_judge.py --log examples/train/train.log \
    --baseline officialB --baseline-log examples/train/official_baseline.log --out out/judge
# 期望：level=pointwise_feasible / NEEDS_EVIDENCE，并打印 verdict_id

# 3) 真机从零（建议先用 --from 跳过已完成阶段，录屏更紧凑）
bash scripts/run_from_zero.sh --from P4
# 期望：逐阶段 PASS/FAIL 表 + out/from_zero_report.md

# 4) 性能窗口
python3 scripts/95_extract_series.py --log out/train/train.log --summary-json out/bench/window_50_100.json
cat out/bench/window_50_100.json           # steps_used / median_ms / samples_per_s
```

## 四、拍摄注意事项

* **不要**在视频里出现：SSH 命令（含 `jt_...` token）、密码、跳板 IP、目标机 IP、`npu-smi` 里的机器标识。
  若必须展示 SSH，请提前把该行用遮挡贴纸挡掉，或录完后剪辑打码。
* 训练阶段的等待请**加速播放**（4×）并标注"已加速"，不要剪掉——"从程序启动开始"是官方要求。
* 若一次录不完，允许分段录，但每段要有**连续的时间戳**，并在结尾说明"各段来自同一次会话"。
* 导出：**MP4（H.264）**，≤ 100 MB，命名 `作品名称+参赛队伍名称_复现视频.mp4`，放 `08_复现视频\`。
