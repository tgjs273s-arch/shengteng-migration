## 状态与交接判定

| 状态 | 含义 |
| --- | --- |
| NOT_STARTED | 尚未开展该任务 |
| IN_PROGRESS | 正在实施 |
| READY_FOR_REVIEW | 已有可审查改动、必要验证及交接，等待复核 |
| ACCEPTED | 任务文件规定的交接条件经复核满足，不自动等于四流程实机通过 |
| WAITING_EXTERNAL | 明确的资料、资源或授权缺失；已完成独立工作，需写出恢复条件 |
| NEEDS_FIX | 复核或实测失败，需要定位修复 |

## 每次任务的固定流程

1. 阅读本任务、上游 handoff、当前源码；检查工作区差异和相关指令。
2. 复现或确认缺口，列出本次会改的文件与接口；必要字段变化更新 INTERFACES.md。
3. 完成限定实现，保留错误状态和回退，不做无依据的大重构。
4. 按任务范围运行测试，保存命令、cwd、解释器、退出码和结果。合成输入明确标记。
5. 用模板编写 `handoffs/Txx.md`，登记实际变更、证据和待测项；同步任务卡和本总表状态为 READY_FOR_REVIEW 或 WAITING_EXTERNAL/NEEDS_FIX。任务卡状态以最新交接为依据，本页创建时的说明仅记录初始状态。
6. 协调者复核验收后放行后继任务。此文档不要求自动提交、推送或创建 PR；如提交，遵循既有授权，不能夹带用户改动。
