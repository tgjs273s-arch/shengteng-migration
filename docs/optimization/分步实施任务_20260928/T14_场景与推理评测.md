## 任务目标

展示迁移后模型真实可用的一个小场景，区分运行成功和业务判断正确。

## 必读输入

- T09 推理入口、T12 已验证模型，若选用 T13 候选需额外核验其产物与精度。
- 明确 SOP、真实图片或视频及其来源；没有标签不做定量正确率声明。

## 允许修改范围

- 一个可观察的小场景、最小标注规范/评分入口、推理测量与错误分析；不默认新增工业专项训练。

## 实施步骤

1. 选择适合输入的任务，静态可见风险可用图片；时序顺序/跳步使用连续帧或视频及明确 SOP，不从单图臆测过程。
2. 划分开发与独立测试数据，避免同一作业过程近邻帧跨集；保存人工标签、模糊样本处理和样本数量/类别分布。
3. 批量执行真实模型推理，保存原文、解析、正确性及失败样本；confidence 不直接视为校准概率。
4. 报告适用的危险召回、漏报/误报、SOP 判定和解析成功率；小样本报告范围与不确定性，不预设 95% 达标。
5. 固定模型/提示/预处理/解码条件测质量变化和延迟；记录 P50/P95、token 数、资源和计时边界，只有可可靠测量才报告 TTFT。
6. 跨 GPU/NPU 比较与同 NPU 优化分开；参考端不可得则标缺证据。若场景不足，提出针对性数据/微调建议，不自行扩展训练任务。
