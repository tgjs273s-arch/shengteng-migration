- T01 的适用基线和别名方案、T02 环境与接口文档。

- P0/P2 的配置选择、P4 资产检查、数据身份和相关最小回归；不改目标模型计算。

## 实施步骤

1. 提供明确的参考复现与候选选择，保存有效配置及全部差异；保留 GBS=8、dp/world 检查和已知后端开关耦合。

3. 统一权重/processor/tokenizer 就绪条件，核验分片索引；DCP 检查格式与必要元信息，不只看目录非空。
4. 记录模型 revision、文件身份和数据转换脚本/参数；校验 JSON 引用图片、样本顺序和实际资产，不用大小/计数替代内容身份。
