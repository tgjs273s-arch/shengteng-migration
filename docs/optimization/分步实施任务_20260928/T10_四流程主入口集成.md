## 实施步骤

1. 采用最小明确模式区分短诊断、参考验收、候选对比和推理；模式名称可按现有 CLI 定案并记入接口，保留旧调用兼容。
2. 绑定 migration_manifest 与训练实际加载源码；引用完整性、精度、性能和 model_artifact/inference_result，增加必需输出及依赖。
3. 优化模式接入 62，数值有效性来自 T07 对应实验产物；禁止靠用户手填 OK 直接绕过。纯基线没有 A/B 时结果为不适用，不凭空构造比较。

5. 更新 OUTPUTS/DEPS、哈希与上下游 attempt；模型、代码、数据、基线或规则变化使相应缓存失效。
6. 必要共享 out/日志/账本坚持单任务；不顺带实现资源调度平台。更新活副本实际能力和主入口说明。
