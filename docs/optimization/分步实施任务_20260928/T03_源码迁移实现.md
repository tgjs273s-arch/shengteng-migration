## 任务目标

交付真正的迁移代码及 Skill/Agent 执行过程，而非只交建议、YAML 或预装框架调用。

## 必读输入

- T01 已核实的 GPU 输入源码、目标框架版本、历史适配审计；SOURCE_PENDING 时不能声称完成本步。
- T02 的目标 API/环境；10_analyze_points.py、20_plan_migration.py、现有 SKILL 及 INTERFACES.md。

## 实施步骤

1. 在独立、明确版本的目标目录工作，保留原始 GPU 源与目标基础框架；已有适配先核回差异和归属，不覆盖其历史内容。
2. 落实模型配置、模型类注册、forward 输入输出、图像/文本处理接口、attention mask/位置编码、loss 接口和参数结构，使目标训练入口能实例化模型。
3. 划分可直接复用的上游实现与本项目必要适配；GPU 专属 import、device、fused 算子等逐项处理。涉及 GDN/causal 的实际算子实现与 T04 衔接，缺失路径不能用占位成功掩盖。
4. 核对预训练权重名称/形状/dtype 到目标参数的映射，拒绝关键参数缺失后的静默随机初始化；转换输出契约与 T08 共用。
5. 让 Skill/Agent 真正应用目标源码或已审查补丁，记录操作、输入与目标代码身份、适配 diff、外部复用和回退方式；不要求通用转换引擎或全部算子自研。
6. 输出 migration_manifest 并说明各项未验证状态；在目标框架已经自带 Qwen 的情况下，明确本步实际工作，不以换名或复制上游充作独立迁移。
