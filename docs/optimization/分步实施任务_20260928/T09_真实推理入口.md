## 任务目标

用本次模型产物做真实推理，可靠记录设备、输入、输出和解析结果。

## 必读输入

- T08 model_artifact、T04 模型执行路径、65_scene.py 和 INTERFACES.md。

## 允许修改范围

- 65_scene.py 的参数、模型加载、生成、结果保存、状态与最小推理指标；必要小型 helper。
- 不在本步建立大规模数据平台或为了演示另训工业模型。

## 实施步骤

1. 显式接收本地模型/processor、产物清单、设备、媒体、SOP 和生成参数；需要原模型对照时作为明确分支，不能替代产物验证。
2. 验证实际加载权重和 NPU 设备、记录推理框架/模型类/后端；训练与推理跨框架时记录边界。
3. 仅解码新增 token，保存原始生成和解析结果；检查 JSON 字段、类型和坐标等契约。
4. 区分执行失败、CPU 回退、解析失败、证据不足与业务判断错误；EXPECTED 保留为示例或夹具，不能作为实际输出兜底。
5. 保存输入/提示/解码参数身份及清楚的耗时范围；无可靠流式时间来源不报告虚构 TTFT。
6. 更正从 P1 静态命中推断运行缺口的旧交叉印证逻辑，静态与运行证据分别记录。
