## 任务目标

建立本次训练运行到可加载模型的唯一对应关系。

## 必读输入

- T03 模型和参数映射、T05 资产/配置、T06 train_run 契约。
- 50_train.py、P2 保存设置、外部框架实际 checkpoint API；不得凭旧脚本参数猜转换命令。

## 允许修改范围

- 按运行隔离的保存配置、checkpoint 清单、实际导出/重载入口及相关测试。
- 本步不实现业务场景评分，也不改候选算法。

## 实施步骤

1. 按运行 ID 定位本次保存目录和训练步；保留 P5 runner 隔离，防止不同运行继续共用外部 save_path。
2. HF 与 DCP 路线分别核对真实格式、必要文件和转换入口；记录源 checkpoint 身份、转换工具版本和参数。
3. 检查参数键、形状、dtype、缺失/额外参数和 tokenizer/processor；缺失不能被原始远程模型兜底。
4. 用固定输入验证保存/导出前后对应输出，区分 bitwise 一致与按 dtype 的数值容差；使用真实模型时保存证据。
5. 产出 model_artifact 清单绑定 migration_id、train_run_id、代码和权重身份；性能诊断允许不保存，但不能用于微调产物推理验收。
